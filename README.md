# MBDNetwork — Financial Market Intelligence Platform

MBDNetwork is a modern financial market intelligence website featuring cryptocurrency market information, financial news, and a responsive dashboard interface.

## Live Website
https://www.mbdnetwork.com/

## Technologies
- Next.js
- React
- TypeScript
- CSS

## Key Features
- Cryptocurrency market dashboard
- Financial news interface
- Responsive website layout
- Reusable React components
- Cookie consent banner

## Public Code Samples
This repository contains selected frontend code samples demonstrating the project's UI architecture, component organization, and frontend development.

The complete production source code, private backend, database, and credentials are not publicly included.
